# packages (apt + dnf)

GitHub Pages hosts free apt and dnf repositories for OpenHat Security CLIs.

Site (after first publish): https://openhat-security.github.io/packages/

Enable **Settings → Pages → Deploy from branch `gh-pages` / root** once the release workflow creates that branch.

Built by `publish-linux-repos` in [openhat-security/runhug](https://github.com/openhat-security/runhug).
